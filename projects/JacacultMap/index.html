Sol-Gui / JacacultMap

Um mapa cultural mobile para explorar e divulgar pontos culturais, eventos, espaços e informações locais em Jacareí.

App online Código
JacacultMap / capturas

Visão geral

JacacultMap foi construído como projeto integrador para o IFSP. O objetivo é tornar a cultura local mais fácil de descobrir pelo celular, usando um mapa interativo e um backend para armazenar pontos culturais.

Destaques

  • Filtros para categorias de eventos e lugares como museus, teatros, shows e exposições.
  • Busca por nome ou localização do ponto cultural.
  • Fluxo para cadastro e atualização de pontos culturais pelo usuário.
  • Interface responsiva otimizada para Android e iOS.

Stack

React Native Node.js Express MongoDB TypeScript
