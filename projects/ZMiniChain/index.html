Visão geral

ZMiniChain foca em aprender detalhes internos da JVM, melhorar a proficiência em Java e implementar conceitos centrais de blockchain sem esconder a camada HTTP atrás do Spring ou de frameworks externos.

Destaques

  • API de blockchain em Java puro com código próprio de request, response, anotações REST e servidor.
  • Modelo de bloco calcula hashes SHA-256 a partir de transações, estado global, timestamp, nonce, hash anterior e índice.
  • Conta genesis e estado do ledger são criados quando a chain inicia.
  • App React Router inclui telas de teste da API e configuração de deploy com Docker.
